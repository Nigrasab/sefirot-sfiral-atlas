# Sefirot–Sfiral Atlas

Интерактивный атлас Древа Сфирот и Сфирали.

## Возможности

- Древо Сфирот с 10 сфиротами и 22 путями
- Названия, ивритские имена, значения, колонны, миры
- Сфираль с параметром `s` и S-петлёй
- Навигатор состояния
- Баланс левой, правой и центральной колонны
- Кратчайший маршрут между сфирот
- Гематрия для ивритских слов
- Энциклопедия

## Локальный запуск

```bash
npm install
npm run dev
